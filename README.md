# Kommuni

**Calm First. Connect Through Music.**

Kommuni is a tablet app for **caregiver–child dyads**. It uses music instead of heavy language to help pairs move from **calming down** to **playing together** (turn-taking and joint attention). Everything runs **on the device** — no cloud.

Built for [Competition name / school project], Expo SDK 57 + TypeScript.

## What the app does

1. **Calm Down** — touch drives gentler, calming music  
2. **Play Together** — turns + camera-based joint attention → harmony rewards  
3. **Data Log** — session notes on the tablet (optional screen)

## Run locally

> **Note:** This app needs a **development build**, not Expo Go (camera + MediaPipe).

```bash
npm install
npx expo prebuild
npx expo run:android   # or iOS
npx expo start --dev-client
